# Project Architecture & Coding Rules

## Overview
This repository contains a full-stack Contact Manager web application built with:
- **Frontend**: React (Vite, JavaScript/JSX, Axios, Lucide React, Plain CSS).
- **Backend**: FastAPI (Python 3.11+, PyMongo `AsyncMongoClient`, Pydantic v2, pytest, httpx).
- **Database**: MongoDB Atlas Free Tier (`contact_manager_db.contacts`).

## Structure Rules
- Keep `frontend/` and `backend/` strictly separated.
- Never mix frontend `node_modules` into `backend/` or Python `.venv` into `frontend/`.
- Frontend HTTP requests must only be routed through `frontend/src/api/contacts.js`. Do not scatter API URLs across components.
- Backend routes in `backend/app/routes/` must remain thin; all MongoDB interactions and business logic reside in `backend/app/services/contact_service.py`.

## Security & Secrets
- Never commit real credentials, database passwords, or `.env` files to git.
- Only tracked `.env.example` files may contain template placeholders.
- Never log full MongoDB connection strings containing passwords.
- Only allow configured frontend origins in FastAPI CORS.

## Data Schema Rules
- MongoDB `_id` is generated by MongoDB as an `ObjectId`.
- API endpoints expose `_id` as a string field named `id`.
- Datetimes (`created_at`, `updated_at`) must always be stored in UTC and serialized as ISO 8601 strings.
- Validate and reject malformed 24-character hexadecimal IDs with HTTP 400.
- Missing records must return HTTP 404.

## Testing Rules
- Automated tests in `backend/tests/test_contacts.py` must run offline by default using dependency injection overrides (`app.dependency_overrides`).
- Integration tests requiring external Atlas credentials must be marked with `@pytest.mark.skipif(not os.getenv("MONGODB_URL"))`.
